الدرس الثاني: العمليات والشروط والحلقات

تعلمي تنفيذ العمليات واتخاذ القرارات وتكرار الأوامر باستخدام JavaScript.

أهداف الدرس

  • التعرف على العمليات الحسابية.
  • استخدام معاملات المقارنة.
  • فهم الجمل الشرطية.
  • التعرف على الحلقات التكرارية.
  • كتابة برامج بسيطة باستخدام JavaScript.

أولًا: العمليات الحسابية Arithmetic Operators

تستخدم العمليات الحسابية لإجراء العمليات الرياضية على الأرقام والمتغيرات.

  • + الجمع.
  • - الطرح.
  • * الضرب.
  • / القسمة.
  • % باقي القسمة.
  • ** الأس.
let x = 10;
let y = 5;

console.log(x + y);
console.log(x - y);
console.log(x * y);
console.log(x / y);
console.log(x % y);

الناتج المتوقع بالترتيب:

15 - 5 - 50 - 2 - 0

ثانيًا: معاملات المقارنة Comparison Operators

تستخدم معاملات المقارنة لمقارنة قيمتين، وتكون النتيجة إما true أو false.

  • == يساوي في القيمة.
  • === يساوي في القيمة ونوع البيانات.
  • != لا يساوي في القيمة.
  • > أكبر من.
  • < أصغر من.
  • >= أكبر من أو يساوي.
  • <= أصغر من أو يساوي.
let age = 20;

console.log(age > 18);
console.log(age === 20);
console.log(age < 15);

الناتج:

true - true - false

ثالثًا: الجمل الشرطية If Statements

تستخدم الجمل الشرطية لتنفيذ أوامر مختلفة حسب تحقق شرط معين.

1- If

تنفذ الأوامر إذا كان الشرط صحيحًا.

let age = 20;

if (age >= 18) {
    console.log("Adult");
}

2- If...Else

تستخدم لتنفيذ أمر إذا تحقق الشرط وأمر آخر إذا لم يتحقق.

let grade = 50;

if (grade >= 50) {
    console.log("Pass");
} else {
    console.log("Fail");
}

3- Else If

تستخدم عند وجود أكثر من شرط.

let grade = 85;

if (grade >= 90) {
    console.log("Excellent");
} else if (grade >= 75) {
    console.log("Very Good");
} else if (grade >= 50) {
    console.log("Pass");
} else {
    console.log("Fail");
}

جربي الشرط بنفسك

رابعًا: الحلقات التكرارية Loops

تستخدم الحلقات التكرارية لتنفيذ مجموعة من الأوامر عدة مرات دون الحاجة إلى كتابة الأوامر نفسها بشكل متكرر.

1- For Loop

تستخدم عندما نعرف عدد مرات التكرار.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

الناتج: 1، 2، 3، 4، 5.

2- While Loop

تستمر في التكرار طالما أن الشرط صحيح.

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

3- Do...While Loop

تنفذ الأوامر مرة واحدة على الأقل، ثم تتحقق من الشرط لتحديد استمرار التكرار. 

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

خامسًا: تطبيق عملي

المثال التالي يستخدم حلقة For لعرض الأرقام من 1 إلى 10. 

let numbers = "";

for (let i = 1; i <= 10; i++) {
    numbers += i + " ";
}

console.log(numbers);
