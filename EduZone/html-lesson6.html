أهداف الدرس

بعد الانتهاء من هذا الدرس ستكون قادرًا على:

  • التعرف على مفهوم النماذج في HTML.
  • إنشاء حقول إدخال البيانات.
  • استخدام أنواع مختلفة من عناصر الإدخال.
  • إنشاء نموذج تسجيل بيانات بسيط.

أولًا: ما المقصود بالنماذج Forms؟

النماذج هي عناصر داخل صفحات الويب تسمح للمستخدم بإدخال البيانات وإرسالها، مثل الاسم والبريد الإلكتروني وكلمة المرور.

تستخدم النماذج في:

  • تسجيل الدخول إلى المواقع.
  • إنشاء حساب جديد.
  • إرسال الرسائل والاستفسارات.
  • تسجيل الطلاب في الدورات التعليمية.

ثانيًا: العنصر Form

نستخدم العنصر <form> لإنشاء نموذج يحتوي على حقول إدخال البيانات.

<form>
  اكتب اسمك:
  <input type="text">
  <button type="submit">إرسال</button>
</form>

ثالثًا: أنواع حقول الإدخال Input

يوفر HTML أنواعًا متعددة من حقول الإدخال، ومنها:

  • text: لإدخال النصوص.
  • password: لإدخال كلمة المرور.
  • email: لإدخال البريد الإلكتروني.
  • number: لإدخال الأرقام.
  • date: لاختيار التاريخ.
  • radio: لاختيار إجابة واحدة من مجموعة.
  • checkbox: لاختيار عنصر واحد أو أكثر.
  • submit: لإرسال النموذج.
<input type="text" placeholder="الاسم">
<input type="email" placeholder="البريد الإلكتروني">
<input type="password" placeholder="كلمة المرور">
<input type="number">
<input type="date">

رابعًا: عناصر أخرى داخل النماذج

1- Label

يستخدم العنصر <label> لكتابة وصف أو عنوان لحقل الإدخال.

<label for="username">الاسم:</label>
<input type="text" id="username">

2- Select

يستخدم لإنشاء قائمة منسدلة تسمح للمستخدم باختيار عنصر.

<select>
  <option>HTML</option>
  <option>CSS</option>
  <option>JavaScript</option>
</select>

3- Textarea

يستخدم لإدخال نصوص طويلة أو رسائل.

<textarea rows="4"></textarea>

4- Button

يستخدم لإنشاء زر لتنفيذ إجراء معين.

<button type="submit">إرسال</button>

خامسًا: مثال عملي على نموذج تسجيل

هذا نموذج تجريبي لتسجيل طالب في منصة EduZone:

ذكر أنثى

ملحوظة: النموذج هنا تجريبي؛ يعرض رسالة تأكيد فقط ولا يحفظ البيانات في قاعدة بيانات.

سادسًا: أهم خصائص النماذج

  • placeholder: تعرض نصًا إرشاديًا داخل الحقل.
  • required: تجعل إدخال البيانات إلزاميًا.
  • value: تحدد قيمة افتراضية للحقل.
  • name: تحدد اسم الحقل عند إرسال البيانات.
  • id: تعطي الحقل معرفًا مميزًا داخل الصفحة.
