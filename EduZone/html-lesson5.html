أهداف الدرس

بعد الانتهاء من هذا الدرس ستكون قادرًا على:

  • التعرف على أنواع القوائم في HTML.
  • إنشاء قوائم مرتبة وغير مرتبة.
  • إنشاء الجداول وتنظيم البيانات داخلها.
  • استخدام عناصر الصفوف والخلايا والعناوين.

أولًا: القوائم في HTML

تستخدم القوائم لتنظيم مجموعة من العناصر وعرضها بطريقة واضحة وسهلة القراءة.

1- القائمة غير المرتبة

نستخدم العنصر <ul> لإنشاء قائمة غير مرتبة، ويظهر بجانب كل عنصر رمز نقطي.

نستخدم العنصر <li> لكتابة كل عنصر داخل القائمة.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

مثال على شكل القائمة:

  • HTML
  • CSS
  • JavaScript

2- القائمة المرتبة

نستخدم العنصر <ol> لإنشاء قائمة مرتبة، وتظهر العناصر بترتيب رقمي افتراضيًا.

<ol>
  <li>فتح VS Code</li>
  <li>إنشاء ملف HTML</li>
  <li>كتابة الكود</li>
</ol>

مثال على شكل القائمة:

  1. فتح VS Code
  2. إنشاء ملف HTML
  3. كتابة الكود

ثانيًا: الفرق بين القوائم المرتبة وغير المرتبة

  • ul: قائمة غير مرتبة تظهر بعلامات نقطية.
  • ol: قائمة مرتبة تظهر بأرقام أو أنواع ترقيم أخرى.
  • li: عنصر داخل القائمة، ويستخدم مع النوعين.

ثالثًا: الجداول في HTML

تستخدم الجداول لتنظيم البيانات في صفوف وأعمدة، مثل جداول الطلاب والدرجات والمنتجات.

أهم عناصر إنشاء الجدول:

  • table: لإنشاء الجدول.
  • tr: لإنشاء صف داخل الجدول.
  • th: لإنشاء خلية عنوان.
  • td: لإنشاء خلية بيانات.
<table>
  <tr>
    <th>الاسم</th>
    <th>الدرجة</th>
  </tr>
  <tr>
    <td>أحمد</td>
    <td>90</td>
  </tr>
</table>

مثال عملي على جدول:

اسم الطالب المادة الدرجة
أحمد HTML 90
سارة CSS 95
محمد JavaScript 85

رابعًا: دمج الخلايا في الجداول

يمكن دمج أكثر من خلية داخل الجدول باستخدام خصائص معينة:

  • colspan: لدمج أكثر من عمود في خلية واحدة.
  • rowspan: لدمج أكثر من صف في خلية واحدة.

مثال على دمج الأعمدة:

<table border="1">
  <tr>
    <th colspan="2">بيانات الطالب</th>
  </tr>
  <tr>
    <td>الاسم</td>
    <td>أحمد</td>
  </tr>
</table>

في هذا المثال، تم دمج عمودين في خلية عنوان واحدة.

خامسًا: تطبيق عملي

أنشئ صفحة HTML تحتوي على قائمة بالمواد التعليمية وجدول بأسماء الطلاب ودرجاتهم.

<h2>المواد التعليمية</h2>
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<h2>درجات الطلاب</h2>
<table border="1">
  <tr>
    <th>الاسم</th>
    <th>الدرجة</th>
  </tr>
  <tr>
    <td>سارة</td>
    <td>95</td>
  </tr>
</table>
