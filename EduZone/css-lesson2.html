الدرس الثاني: تنسيق العناصر

تعلمي كيفية التحكم في ألوان النصوص والخلفيات والخطوط والمسافات.

أهداف الدرس

  • التعرف على خصائص الألوان والخلفيات.
  • التحكم في نوع الخط وحجمه وشكله.
  • التعرف على خصائص الحدود.
  • فهم نموذج الصندوق Box Model.
  • التمييز بين Margin وPadding.

أولًا: الألوان والخلفيات

توفر CSS مجموعة من الخصائص التي تساعدنا على تغيير ألوان العناصر والخلفيات داخل صفحة الويب.

خاصية Color

تستخدم لتغيير لون النص.

h1 {
    color: blue;
}

خاصية Background-color

تستخدم لتغيير لون خلفية العنصر.

body {
    background-color: lightblue;
}

خاصية Background-image

تستخدم لإضافة صورة كخلفية للعنصر.

body {
    background-image: url("background.jpg");
}

ثانيًا: تنسيق النصوص والخطوط

يمكن التحكم في شكل النصوص باستخدام خصائص مختلفة، منها:

  • Font-size: لتحديد حجم الخط.
  • Font-family: لتحديد نوع الخط.
  • Font-weight: لتحديد سمك الخط.
  • Text-align: لتحديد محاذاة النص.
  • Text-decoration: لإضافة خط أسفل النص أو إزالته.
h2 {
    font-size: 28px;
    font-family: Arial;
    font-weight: bold;
    text-align: center;
}

p {
    text-decoration: underline;
}

عنوان تجريبي

نص تحته خط باستخدام CSS.

ثالثًا: الحدود Border

تستخدم خاصية Border لإضافة حدود حول العناصر، ويمكن تحديد سمك الحدود ونوعها ولونها. 

div {
    border: 2px solid blue;
}

ومن أنواع الحدود:

  • Solid: خط متصل.
  • Dashed: خط متقطع.
  • Dotted: نقاط متتابعة.
  • Double: خط مزدوج.
هذا مثال على حدود متقطعة حول عنصر.

رابعًا: نموذج الصندوق Box Model

تتعامل CSS مع كل عنصر في صفحة الويب باعتباره صندوقًا، ويتكون هذا الصندوق من أربعة أجزاء أساسية:

  • Content: المحتوى الموجود داخل العنصر.
  • Padding: المسافة الداخلية بين المحتوى والحدود.
  • Border: الحدود المحيطة بالعنصر.
  • Margin: المسافة الخارجية بين العنصر والعناصر الأخرى.
.box {
    width: 200px;
    padding: 20px;
    border: 5px solid blue;
    margin: 15px;
}
Content

المثال يوضح المسافة الداخلية والحدود والمسافة الخارجية.

خامسًا: الفرق بين Margin وPadding

Margin: مسافة خارج العنصر تفصله عن العناصر الأخرى.

Padding: مسافة داخل العنصر بين المحتوى والحدود.

.card {
    margin: 20px;
    padding: 15px;
}

اختبر فهمك

1- ما الخاصية المستخدمة لتغيير لون النص؟



2- ما الخاصية المسؤولة عن المسافة الداخلية للعنصر؟



3- أي جزء يمثل الحدود المحيطة بالعنصر؟
