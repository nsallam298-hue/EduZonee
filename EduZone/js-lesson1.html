الدرس الأول: أساسيات JavaScript

تعلمي أساسيات البرمجة باستخدام JavaScript وإضافة التفاعل إلى صفحات الويب.

أهداف الدرس

  • التعرف على لغة JavaScript وأهميتها.
  • معرفة كيفية إضافة JavaScript إلى صفحة HTML.
  • التعرف على المتغيرات وطرق تعريفها.
  • فهم أنواع البيانات الأساسية.
  • كتابة أوامر برمجية بسيطة.

أولًا: ما هي JavaScript؟

JavaScript هي لغة برمجة تُستخدم لإضافة التفاعل والحركة والوظائف المختلفة إلى صفحات الويب.

تساعدنا JavaScript على:

  • إظهار رسائل للمستخدم.
  • الاستجابة للنقر على الأزرار.
  • التحقق من البيانات المدخلة في النماذج.
  • تغيير محتوى الصفحة دون إعادة تحميلها.
  • إنشاء اختبارات وألعاب تفاعلية.

ثانيًا: طرق إضافة JavaScript

1- Internal JavaScript

نكتب الكود داخل وسم script في صفحة HTML.

<script>
    alert("Welcome to EduZone");
</script>

2- External JavaScript

نكتب الكود في ملف خارجي بامتداد js، ثم نربطه بصفحة HTML. 

<script src="script.js"></script>

وتُعد الطريقة الخارجية مناسبة لتنظيم الأكواد وإعادة استخدامها في أكثر من صفحة.

ثالثًا: المتغيرات Variables

المتغير هو مكان في الذاكرة نستخدمه لتخزين البيانات حتى نتمكن من استخدامها أثناء تنفيذ البرنامج.

هناك ثلاث كلمات أساسية لتعريف المتغيرات:

  • let: لتعريف متغير يمكن تغيير قيمته.
  • const: لتعريف متغير لا يمكن إعادة إسناد قيمة جديدة له.
  • var: طريقة قديمة لتعريف المتغيرات.
let studentName = "Nada";

const age = 20;

var city = "Fayoum";

مثال على تغيير قيمة متغير:

let score = 10;

score = 20;

console.log(score);

الناتج المتوقع من المثال السابق:

20

رابعًا: أنواع البيانات Data Types

تتعامل JavaScript مع أنواع مختلفة من البيانات، ومنها:

1- String

تستخدم لتخزين النصوص.

let name = "Ahmed";

2- Number

تستخدم لتخزين الأرقام.

let age = 21;
let price = 50.5;

3- Boolean

تستخدم لتخزين إحدى قيمتين: true أو false.

let isStudent = true;

4- Undefined

تظهر عندما يتم تعريف متغير دون إعطائه قيمة.

let result;

5- Null

تستخدم للتعبير عن عدم وجود قيمة مقصودة.

let user = null;

خامسًا: عرض النتائج

يمكن استخدام عدة طرق لعرض النتائج أثناء كتابة الكود.

  • console.log(): لعرض النتائج في وحدة التحكم.
  • alert(): لإظهار رسالة منبثقة.
  • document.write(): لكتابة محتوى داخل الصفحة.
let name = "Nada";

console.log(name);

alert("Welcome to EduZone");
