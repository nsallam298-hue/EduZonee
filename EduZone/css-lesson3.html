الدرس الثالث: تصميم صفحات الويب

تعلمي كيفية ترتيب العناصر وإنشاء تصميم متجاوب باستخدام CSS.

أهداف الدرس

  • التعرف على Flexbox واستخداماته.
  • التعرف على CSS Grid.
  • فهم مفهوم التصميم المتجاوب Responsive Design.
  • إنشاء تخطيط بسيط لصفحة ويب.

أولًا: ما هو Flexbox؟

Flexbox هو نظام تخطيط في CSS يساعد على ترتيب العناصر داخل الحاوية والتحكم في توزيع المساحات بينها.

من أهم خصائص Flexbox:

  • display: flex: تفعيل نظام Flexbox.
  • justify-content: التحكم في توزيع العناصر أفقيًا.
  • align-items: محاذاة العناصر على المحور الآخر.
  • flex-direction: تحديد اتجاه ترتيب العناصر.
  • flex-wrap: السماح للعناصر بالانتقال إلى سطر جديد.
.container {
    display: flex;
    justify-content: space-around;
    align-items: center;
    gap: 10px;
}

ثانيًا: ما هو CSS Grid؟

CSS Grid هو نظام تخطيط يُستخدم لإنشاء تصميمات تعتمد على الصفوف والأعمدة، ويساعد في تنظيم العناصر داخل الصفحة.

من أهم خصائصه:

  • display: grid: تفعيل نظام Grid.
  • grid-template-columns: تحديد عدد الأعمدة وأحجامها.
  • grid-template-rows: تحديد الصفوف.
  • gap: تحديد المسافات بين العناصر.
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

ثالثًا: التصميم المتجاوب Responsive Design

التصميم المتجاوب هو أسلوب يجعل صفحة الويب تتكيف مع أحجام الشاشات المختلفة، مثل الكمبيوتر والتابلت والموبايل.

نستخدم Media Queries لتغيير شكل التصميم حسب عرض الشاشة. 

@media (max-width: 600px) {
    .container {
        grid-template-columns: 1fr;
    }
}

في المثال السابق، عندما يصبح عرض الشاشة 600 بكسل أو أقل، تتحول الأعمدة إلى عمود واحد.

رابعًا: تطبيق عملي

لننشئ مجموعة بطاقات باستخدام Grid، مع تغيير عدد الأعمدة حسب حجم الشاشة. 

<div class="cards">
    <div>HTML</div>
    <div>CSS</div>
    <div>JavaScript</div>
</div>
.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

.cards div {
    background: #24577A;
    color: white;
    padding: 25px;
    text-align: center;
}

@media (max-width: 600px) {
    .cards {
        grid-template-columns: 1fr;
    }
}
