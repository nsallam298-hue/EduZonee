الدرس الثالث: الدوال والأحداث وDOM

تعلمي كيفية إنشاء وظائف برمجية وإضافة التفاعل إلى عناصر صفحة الويب.

أهداف الدرس

  • التعرف على مفهوم الدوال Functions.
  • تعلم كيفية إنشاء واستدعاء الدوال.
  • التعرف على الأحداث Events.
  • فهم مفهوم DOM.
  • التعامل مع عناصر HTML باستخدام JavaScript.

أولًا: ما هي الدوال Functions؟

الدالة هي مجموعة من الأوامر البرمجية يتم تجميعها لتنفيذ مهمة محددة، ويمكن استدعاؤها عند الحاجة.

تساعد الدوال على:

  • تنظيم الكود البرمجي.
  • تقليل تكرار الأوامر.
  • إعادة استخدام الكود أكثر من مرة.
  • تقسيم البرنامج إلى أجزاء صغيرة.

طريقة إنشاء دالة

function sayHello() {
    console.log("Hello");
}

sayHello();

نستخدم الكلمة function لإنشاء الدالة، ثم نكتب اسمها ونضع الأوامر داخل الأقواس المعقوفة.

الدوال التي تستقبل Parameters

function welcome(name) {
    console.log("Welcome " + name);
}

welcome("Nada");

يمكن للدالة استقبال بيانات من خلال Parameters، ثم استخدام هذه البيانات داخل الدالة.

استخدام Return

function add(a, b) {
    return a + b;
}

let result = add(5, 3);

console.log(result);

تُستخدم return لإرجاع نتيجة من الدالة.

ثانيًا: الأحداث Events

الأحداث هي أفعال يقوم بها المستخدم أو المتصفح، وتسمح لنا JavaScript بالاستجابة لهذه الأفعال.

من أشهر الأحداث:

  • onclick: عند الضغط على عنصر.
  • onchange: عند تغيير قيمة عنصر.
  • onmouseover: عند مرور مؤشر الفأرة فوق عنصر.
  • onkeydown: عند الضغط على أحد أزرار لوحة المفاتيح.
  • onsubmit: عند إرسال نموذج.

مثال على حدث النقر

<button onclick="showMessage()">
    Click Me
</button>

<script>
function showMessage() {
    alert("Welcome!");
}
</script>

ثالثًا: ما هو DOM؟

DOM اختصار لـ Document Object Model، وهو نموذج يسمح لـ JavaScript بالتعامل مع عناصر صفحة HTML وتغييرها.

من خلال DOM يمكننا:

  • الوصول إلى عناصر HTML.
  • تغيير النصوص داخل العناصر.
  • تغيير الألوان والخلفيات.
  • إضافة عناصر جديدة أو حذف عناصر موجودة.
  • الاستجابة لتفاعلات المستخدم.

الوصول إلى عنصر باستخدام ID

document.getElementById("title");

الوصول إلى العناصر باستخدام Class

document.getElementsByClassName("item");

الوصول إلى العناصر باستخدام Tag

document.getElementsByTagName("p");

تغيير محتوى عنصر

document.getElementById("title").textContent =
    "Welcome to EduZone";

رابعًا: تغيير شكل عناصر الصفحة

يمكن استخدام JavaScript لتغيير خصائص CSS الخاصة بالعناصر الموجودة في صفحة HTML. 

document.getElementById("title").style.color = "blue";

document.getElementById("title").style.fontSize = "30px";

خامسًا: تطبيق عملي

سننشئ نموذجًا بسيطًا يستقبل اسم المستخدم، ثم يعرض رسالة ترحيب. 

function welcomeUser() {
    let name = document.getElementById("username").value;

    document.getElementById("message").textContent =
        "Welcome " + name;
}
