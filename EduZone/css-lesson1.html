الدرس الأول: أساسيات CSS

تعلمي كيف تتحكمين في شكل صفحات الويب وتنسيقها.

أهداف الدرس

  • التعرف على مفهوم CSS وأهميتها.
  • معرفة طرق إضافة CSS إلى صفحات HTML.
  • التعرف على المحددات Selectors.
  • كتابة تنسيقات بسيطة باستخدام CSS.

أولًا: ما هي CSS؟

CSS هي اختصار لـ Cascading Style Sheets، وهي لغة تستخدم لتنسيق صفحات الويب والتحكم في مظهر عناصر HTML.

من خلال CSS يمكننا التحكم في:

  • ألوان النصوص والخلفيات.
  • أحجام الخطوط وأنواعها.
  • المسافات بين العناصر.
  • أحجام العناصر ومواقعها.
  • شكل الصفحة على الشاشات المختلفة.

ثانيًا: طرق إضافة CSS

1- Inline CSS

تُكتب داخل العنصر نفسه باستخدام الخاصية style.

<p style="color: blue;">
    Welcome to EduZone
</p>

2- Internal CSS

تُكتب داخل وسم style في قسم head بصفحة HTML.

<head>
    <style>
        p {
            color: blue;
        }
    </style>
</head>

3- External CSS

تُكتب في ملف خارجي بامتداد css، ثم نربطه بصفحة HTML.

<link rel="stylesheet" href="style.css">

وهذه الطريقة مناسبة للمواقع التي تحتوي على صفحات متعددة.

ثالثًا: المحددات Selectors

المحددات تُستخدم لاختيار عناصر HTML التي نريد تنسيقها.

1- Element Selector

يستخدم اسم العنصر لتنسيق جميع العناصر من النوع نفسه.

p {
    color: red;
}

2- Class Selector

يستخدم النقطة (.) قبل اسم الفئة لتنسيق العناصر التي تحمل نفس class.

.title {
    color: blue;
}

3- ID Selector

يستخدم العلامة (#) قبل اسم المعرف لتنسيق عنصر محدد.

#main {
    background-color: yellow;
}

مثال تطبيقي

الكود التالي يوضح كيفية استخدام CSS لتنسيق عنوان وفقرة:

<h1 class="title">Welcome to EduZone</h1>
<p id="info">Learn web design easily.</p>

<style>
    .title {
        color: blue;
    }

    #info {
        color: gray;
    }
</style>
