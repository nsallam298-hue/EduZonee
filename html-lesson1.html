الدرس الأول: مقدمة في HTML

في هذا الدرس سنتعرف على لغة HTML، وأهميتها في إنشاء صفحات الويب، وكيفية استخدامها لبناء الهيكل الأساسي للموقع.

مدة الدرس المقترحة: 15 دقيقة

أهداف الدرس

بنهاية هذا الدرس ستكونين قادرة على:

  • تعريف لغة HTML.
  • فهم أهمية HTML في تصميم المواقع.
  • التعرف على استخدامات اللغة.
  • التمييز بين HTML وCSS وJavaScript.

ما هي HTML؟

HTML هي اختصار لعبارة HyperText Markup Language، وتعني لغة توصيف النص التشعبي.

تُستخدم HTML لإنشاء الهيكل الأساسي لصفحات الويب، فهي تحدد أماكن العناوين والفقرات والصور والروابط والجداول وغيرها من العناصر.

لا تُعد HTML لغة برمجة بالمعنى التقليدي، بل هي لغة توصيف تساعد المتصفح على فهم وتنظيم محتوى الصفحة.

معلومة مهمة: عند فتح أي موقع إلكتروني، يقوم المتصفح بقراءة كود HTML وعرض عناصر الصفحة للمستخدم بالشكل المناسب.

أهمية HTML

  • إنشاء صفحات ومواقع الويب.
  • تنظيم النصوص والعناوين داخل الصفحة.
  • إضافة الصور والروابط.
  • إنشاء القوائم والجداول.
  • إنشاء النماذج لإدخال البيانات.
  • توفير الهيكل الذي تعتمد عليه لغات تصميم وتطوير الويب الأخرى.

الفرق بين HTML وCSS وJavaScript

تعمل هذه التقنيات معًا لإنشاء مواقع ويب متكاملة، ولكل واحدة منها وظيفة مختلفة:

  • HTML: مسؤولة عن بناء هيكل الصفحة ومحتواها.
  • CSS: مسؤولة عن الألوان والتنسيق والتصميم.
  • JavaScript: مسؤولة عن إضافة التفاعل والوظائف البرمجية.
تخيلي أن HTML هي هيكل المنزل، وCSS هي الديكورات والألوان، وJavaScript هي الأنظمة التي تجعل المنزل أكثر تفاعلًا.

مثال عملي بسيط

يمكننا استخدام HTML لإنشاء عنوان وفقرة داخل صفحة ويب. 

<h1>Welcome to EduZone</h1>

<p>Learn something new every day.</p>

عند عرض هذا الكود في المتصفح سيظهر:

Welcome to EduZone

Learn something new every day.

استخدمنا العنصر h1 لإنشاء عنوان رئيسي، والعنصر p لإنشاء فقرة نصية.

تطبيق عملي

افتحي برنامج VS Code، وأنشئي ملفًا جديدًا باسم my-first-page.html، ثم اكتبي الكود التالي: 

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>

<body>
    <h1>Hello World</h1>
    <p>This is my first web page.</p>
</body>
</html>

احفظي الملف وافتحيه باستخدام المتصفح، ولاحظي ظهور العنوان والفقرة.
